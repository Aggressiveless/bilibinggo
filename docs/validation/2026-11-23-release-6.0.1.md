## 构建与升级方案

- 使用登记工作区构建并运行包级启动验证；发布清单记录该提交、实际构建结果与 SHA-256。
- 发行包仅收录程序和内置资源，不包含构建冒烟测试生成的数据、个人凭据或任务记录。
- 升级前再次检查业务队列、运行任务及自动工作流；仅在空闲时切换程序。
- 备份程序和完整用户数据，以 SQLite backup 生成一致数据库副本；保留旧程序用于恢复。
- 通过连接器正常停止、切换并启动登记实例，不执行安装器或强制结束业务进程。
- 升级后核验实例版本、数据根、配置摘要及业务表内容，并对实际安装版复查项目区。

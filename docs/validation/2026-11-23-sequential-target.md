# 顺序参与与目标新视频检索验收

版本：`5.0.5+repostfix.18`。沿用现有工程、统一任务队列、用户数据与历史记录。

## 活动参与

- 活动页改为“自动顺序参与”，移除旧三条目标卡片及固定 3 条入口。
- 新动作 `participate_sequential` 在执行时按当前筛选与排序重新选取全部可参与的未参加活动，跨越列表分页，严格逐项执行。
- 每项保留参与前实时检查；遇到失败停止后续项，记录已成功、失败和未执行数量。
- 空闲时执行，忙碌时排队；进度和结果继续进入统一日志页。
- 简化参与区布局；参与按钮和热度数字保持横排。已检查桌面深色界面及 390px 手机布局。
- 原有历史数据及内部兼容接口保留，历史记录没有改写。

## 目标新视频检索

- 新增目标输入，默认 100，可设置 1–10000 的整数；最新发布和综合排序均支持持续翻页。
- 在任务执行时读取持久化 BV 库。已有 BV、同页重复、跨页重复和跨关键词重复均不计入目标；多余的新结果留给后续任务。
- 只扫描本任务新接收的唯一 BV，达到目标后停止收集并完成关联核验。目标计数是视频数量，与可参与活动数量分开。
- 保存页码、已接收 BV 和已扫描游标；暂停后继续不会重复扫描或重新计算自己的 BV。
- 限流和停止仍保存进度。搜索结果不足时显示“新视频不足”和实际进度；日志不会把 12/100 改成 100/100。无分页信息且平台重复返回最后一页时会结束，避免无限请求。
- 旧版检索记录显示“上次扫描视频”，不会冒充本轮新增数量。

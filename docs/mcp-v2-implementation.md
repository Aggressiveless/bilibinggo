## 收藏问题

真实只读响应中，三条受影响动态的统计字段包含 `favorite: null`。旧代码只判断键是否存在，将其误认为可收藏；随后平台返回 `code=0,message="0"`，但状态查询没有收藏字段，最终把整项参与显示为失败“0”。旧规则匹配还遗漏了“关&转&赞&评”以及连写的“转发评论点赞”。

现已正确识别空收藏入口、两种 modules 形状及缩写/连写规则。不要求收藏时跳过收藏请求；明确要求收藏却无入口时仍判失败。无法核验收藏时显示清楚的原因，失败任务保留已经完成的步骤。重试复用账号对应的成功转发/评论回执，防止为了重试收藏再次发帖；平台核验始终重新读取，不把本地回执冒充实时核验。

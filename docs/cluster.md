
# Binggo 工作集群

每台机器登录自己的 B 站账号后，可以参与关键词检索并同步活动。使用支持两阶段协作的版本，并完成本机模型设置及连接测试后，该节点也可以领取视频检测任务。

1. 在主机打开 **工作集群**，填写主服务器的 HTTPS 地址和本机节点名，点击 **发起工作集群**。
2. 点击 **显示邀请码**，把同一 HTTPS 地址和邀请码交给计划加入的节点管理员。
3. 其它机器在自己的 Binggo 页面选择 **参与工作集群**，输入本机节点名、地址和邀请码。主机也会领取任务。节点重启后自动恢复同步。
4. 「检索集合」显示检索页数与视频收录进度。「分配检测」显示待检测、检测中、已检测的视频数量和各节点状态。「集群管理」提供地址、邀请码和退出入口。暂停仅停止领取新任务。解散后成员需要退出旧集群并重新加入。

## 主服务器入口

中心与本地仪表盘使用同一个 Binggo 进程。中心数据库位于主服务器的 BINGGO_HOME/data/cluster/cluster.db，普通成员通过 HTTPS 调用 v1 协议，不访问数据库。中心初期可使用单机 SQLite，不需要增加数据库服务。将集群目录与普通账号数据一起纳入异机备份，恢复时保持中心的集群标识和同步游标。SQLite 在线快照适合运行期间的备份。

如果主机的 Nginx 已对仪表盘启用 HTTP Basic Auth，在已配置好证书的 HTTPS server 中单独添加以下位置。集群接口使用邀请码或各节点自己的 Bearer 凭据，仪表盘其它路径沿用原有认证。将端口改成本机 Binggo 监听端口。

    location ^~ /api/cluster/peer/v1/ {
        auth_basic off;
        client_max_body_size 256k;
        proxy_set_header Host 127.0.0.1:8182;
        proxy_set_header Authorization $http_authorization;
        proxy_pass http://127.0.0.1:8182;
    }

邀约与管理面板应只交给有权操作的用户。邀约码用于加入，已加入节点继续使用各自独立的凭据。主机可按可信内网或节点 IP 配置入口访问范围。HTTP 仅用于本机回环测试。

## 调度与活动同步

每轮先分配关键词检索任务。各节点检索不同结果页，主节点按 BV 去重并收录视频，跳过近期已检测的视频。检索词包括「抽奖」「福利」「奖品」「转发抽奖」「抽奖活动」「粉丝福利」，按发布时间和综合排序分别检索，每个查询最多 60 页。

收录达到 1,000 个视频后，主节点停止派发新搜索页，等已领搜索任务返回后开始分配视频检测。若可用结果页已搜完，主节点检测已有视频。每个节点同时执行一项，全组最多四项。平台限流时暂停领取新任务至冷却结束。整轮达标且全部任务完成后约 30 分钟开启下一轮，收录不足或有永久失败时约 60 分钟开启下一轮。

检索页数按成功完成的搜索页任务计算。升级前已经清理的轮次无法补计，页面会显示累计统计起始轮次。

视频转化率按“核验到至少一项开放活动的视频数 ÷ 有统计记录且已完成检测的视频数”计算。工作集群页显示全组转化率，主动检索页显示本机转化率。「数据源 → 主动检索 → 成果展示」的「集群检出活动」按截止时间列出仍开放的动态，同一动态只计一次。团队成员上传的已有活动继续同步。

节点批量上传本地已知、仍开放、时间明确的活动。主机验证字段并按动态 ID 汇总，向主机自身和其它节点按游标同步新增、更新和核验关闭状态。既有的本地活动与账号参与记录由本地流程管理。共享条目的时间及简要信息可在活动页查看。Cookie、参与记录和 API Key 均不随协议传输。

检索任务返回视频 BV。视频检测在同一个任务内检查视频及关联动态、专栏、短链和发布者线索，确认的活动由主节点自动同步。节点会定期续租，失联超时后任务可由其它节点领取。未确认提交的结果在恢复连接后补交。正文分析结果按完整输入、提示词和模型配置共用 30 天缓存。

## 集群工作日志

「日志」页显示任务队列和集群工作日志。集群工作日志默认显示本机集群任务和全组调度事件，可切换到全部节点或仅看异常。

主节点保存最近 2,000 条事件，界面同步其中最新 80 条。日志记录领取、完成、重新派发、限流和活动同步，使用固定错误原因，不记录账号凭据、模型密钥和请求原文。已存在的集群从升级后开始记录。

「数据源 → 主动检索」显示本机领取的集群任务、本轮贡献及近期结果。页数、去重后收录的视频和核验结果只计本节点完成的集群任务。独立检索仍使用原来的统计。正在运行的集群从升级后开始统计本轮新增贡献。
